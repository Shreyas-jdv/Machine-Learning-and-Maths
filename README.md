## 📋 Outline & Topics Covered

* **Mathematical Background Revisit**
  * Linear Algebra Revision (Vectors, vector operations, $p$-norms, Euclidean distance, and cosine similarity)
  * Matrices and Tensors (2D and multi-dimensional tensor definitions and operations)
  * Information Theory Revision (Kullback-Leibler divergence, Shannon entropy, and cross-entropy)
* **Machine Learning**
  * Historical context and core definitions of Machine Learning
  * Elements of Machine Learning (Data, Model, and Assessment metrics like Accuracy)
  * Supervised Learning tasks: Classification and Regression
* **Discriminative Machine Learning & Logistic Regression**
  * Discriminative models and Softmax activation function
  * Cross-entropy loss function
  * Logistic Regression pipeline, forward computation, mini-batch loss, and optimization
* **Appendix**
  * The Five Tribes of Machine Learning (Symbolists, Evolutionary, Connectionists, Bayesians, and Analogizers)
